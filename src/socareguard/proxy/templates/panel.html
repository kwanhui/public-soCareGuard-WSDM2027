SoCareGuard is an OpenAI-compatible endpoint. Point any client at it and add one header naming the policy pack.

from openai import OpenAI
client = OpenAI(base_url="{{ base_url }}/v1", api_key="{{ 'your-key' if auth_required else 'not-required' }}")
reply = client.chat.completions.create(
    model="{{ models[0] }}",
    messages=[{"role": "user", "content": "Summarise this note...\n\n<case note>"}],
    extra_headers={"X-SoCareGuard-Pack": "{{ default_pack }}", "X-SoCareGuard-Actor": "sw-042"},
)

The reply carries a socareguard object with the decision, flags (evidence and rewrite already re-identified), event stream, every recipient of the pseudonymised text, the session token that opens the session's identity map, and the ledger row. X-SoCareGuard-Audience: internal|external overrides the audience read from the instruction. GET /v1/ledger?session=… lists the rows; GET /v1/ledger/verify recomputes the chain; DELETE /v1/sessions/… purges a session's identity map and records that it did.
