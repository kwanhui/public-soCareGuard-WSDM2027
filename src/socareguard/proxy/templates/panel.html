SoCareGuard is an OpenAI-compatible endpoint. Point any client at it and add one header naming the policy pack.

from openai import OpenAI
client = OpenAI(base_url="{{ base_url }}/v1", api_key="{{ 'your-key' if auth_required else 'not-required' }}")
reply = client.chat.completions.create(
    model="{{ models[0] }}",
    messages=[{"role": "user", "content": "Summarise this note...\n\n<case note>"}],
    extra_headers={"X-SoCareGuard-Pack": "{{ default_pack }}", "X-SoCareGuard-Actor": "sw-042"},
)

The reply carries a socareguard object with the decision, flags (evidence and rewrite already re-identified), event stream, every recipient of the pseudonymised text, the session token that opens the session's identity map, and the ledger row. X-SoCareGuard-Audience: internal|external overrides the audience read from the instruction. A request without X-SoCareGuard-Pack runs the deployment's default pack, and its response carries the header X-SoCareGuard-Pack-Defaulted: true. GET /v1/ledger?session=… lists the rows. GET /v1/ledger/verify recomputes the chain. DELETE /v1/sessions/… purges a session's identity map and records that it did.

1. What you typed

Highlights show what the guard changed before anything left. Hover a highlight for the rule.

      
2. What left the premises
Direct identifiers are replaced by surrogates, and quasi-identifiers and sensitive attributes are generalised. Surrogates are per person and stay the same within a session, so two people who share a surname receive unrelated surrogate surnames. The instruction line (first paragraph) is pseudonymised but not generalised. Detection misses some attribute spans (recall by category in docs/metrics.md), so read this column before relying on the guard. A named employer leaves as an invented name for an internal audience and as "an employer" for an external one. The identity map never leaves this server.

      
3. What came back
The model's reply as received. It is screened in this form, before anything is re-identified.

      
4. What you see
Re-identified on this server. Flagged text is underlined in red. A generalised phrase that cannot come back keeps its colour (hover for what the record says). A withheld or generalised phrase that the model repeated exactly is restored from the record and underlined in dots. An orange mark is a surrogate fragment that the model reformatted.
