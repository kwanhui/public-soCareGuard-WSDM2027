# Demo materials

Materials for the WSDM 2027 Demonstrations submission and for reviewer-facing demos.

## Contents

- `sample-inputs/scenarios/*.jsonl` holds the four Use Case scripts, plus `escalation.jsonl`
  (a recorded reply for the escalation chip), as replayable JSONL event streams. They are built
  from `socareguard/scenarios/authoring.py` and can be rebuilt with
  `python3 -m socareguard.scenarios build`. Each script carries the practitioner's raw input, the
  pseudonymised payload, the model reply, and `expect` lines that the proxy must satisfy.
- `scenarios.md` is a human-readable storyboard of the four scripts, generated by
  `python3 -m socareguard.scenarios storyboard`. The demo video follows this walkthrough.
- `screenshots/` contains full-page panel screenshots for the four scenarios (`uc1-panel.png` to
  `uc4-panel.png`), taken during the first video recording.

## Use Cases

| | Pack | What it shows |
|---|---|---|
| UC1 | youth offending | Full name, NRIC, Youth Court reference and school leave the premises as surrogates and banded forms. The ledger row records what left, to whom, and the transfer-basis statement that the deployer sets through `SOCAREGUARD_TRANSFER_BASIS` (the sandbox uses the default statement). |
| UC2 | domestic violence | Shelter, school and estate are generalised, not merely renamed. Asked for a frank summary, the model escalates into blaming language about a survivor's ambivalence, flagged against SASW A.7.c with a neutral rewrite. |
| UC3 | disability | An introduction note to a cafe supervisor that tells the employer her diagnosis, or frames her decision as subject to a capacity review. The draft is not toxic, so the harm classifier is silent, and the screener annotates A.6.d or A.2.a-b with a needs-only rewrite. |
| UC4 | need-to-know | A one-line risk note in the instruction is forwarded to admin in a room-booking email and flagged as disclosure beyond need (A.6.d). The practitioner overrides with a protocol reason and the ledger row shows it. |

The UC4 script keeps the file id `uc4-over-caution-override` from an earlier plan. The use case is
need-to-know and override, as the over-caution class did not appear on this task and is measured
on the drafts corpus instead.

Model replies are recorded live through the proxy (`source: recorded`, model and timestamp in
the file). `python3 -m socareguard.scenarios run --proxy` replays them through the guard with the
live judge. All assertions pass at tag `results-v1.2`, the results the paper reports.

## Hosted demo

The hosted demo runs at https://huggingface.co/spaces/kwanhui/socareguard, a Space with the
Docker SDK and with the provider keys held as Space secrets. The Space is a labelled
synthetic-data sandbox with a per-address rate limit (`SOCAREGUARD_MAX_REQUESTS_PER_HOUR`), and
`docker compose up` provides the on-premise path for reproducing the demo.

We recorded the final cut of the demo video on 2026-09-07 (2:32, captions only, no audio, with
live model replies). The video was produced with separate recording tooling that is not part of
this repository, and a link to it will be added here.
